To install **MARUS2 Sensors gRPC** and its required core dependencies, add them directly to your Unity project's **`Packages/manifest.json`** file under the `"dependencies"` block:

```json
{
  "dependencies": {
    "com.marus2.proto": "https://github.com/MARUSimulator/marus2-proto.git#csharp",
    "com.marus2.core": "https://github.com/MARUSimulator/marus2-core.git",
    "com.marus2.sensors": "https://github.com/MARUSimulator/marus-sensors.git",
    "com.labust.marus2.sensors-grpc": "https://github.com/MARUSimulator/marus-sensors-grpc.git"
  }
}
```

# Sensor gRPC usage

To integrate sensor streaming into a Unity scene, attach the corresponding `*gRPC.cs` component to the GameObject containing the sensor. Sensor data is published through gRPC to the topic specified in the "Address" property of the component.

### ROS Integration

ROS communications are enabled by the `RosConnection` singleton connecting to the gRPC-ROS adapter server.
To run the ROS adapter backend:

```bash
ros2 launch grpc_ros_adapter ros2_server_launch.py
```

## AIS

Streams AIS sensor information over gRPC.
* **ROS Topic Type**: `uuv_sensor_msgs/msg/AISPositionReport`

## GPS/GNSS

Streams geographic coordinates (latitude, longitude, altitude) and position covariance over gRPC.
* **ROS Topic Type**: `sensor_msgs/msg/NavSatFix`

## IMU

Streams orientation (quaternion), angular velocity, and linear acceleration from the vehicle's RigidBody.
* **ROS Topic Type**: `sensor_msgs/msg/Imu`

## Lidar

Streams 3D point cloud measurements generated by the LiDAR raycaster.
* **ROS Topic Type**: `sensor_msgs/msg/PointCloud2`

## Camera

Streams image frames captured by the camera sensor.
* **ROS Topic Type**: `sensor_msgs/msg/Image`

## Depth Sensor

Streams vehicle depth relative to the water surface.
* **ROS Topic Type**: `geometry_msgs/msg/PoseWithCovarianceStamped`

## DVL Sensor

Streams ground-referenced linear velocity (velocity relative to the seafloor) and altitude.
* **ROS Topic Type**: `geometry_msgs/msg/TwistWithCovarianceStamped`

## Sonar

Streams 2D polar or Cartesian acoustic sonar images.
* **ROS Topic Type**: `sensor_msgs/msg/Image`

## Pose Sensor

Streams ground-truth vehicle local position, orientation, linear velocity, and angular velocity.
* **ROS Topic Type**: `geometry_msgs/msg/PoseWithCovarianceStamped`
